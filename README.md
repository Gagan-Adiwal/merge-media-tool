# 🎬 Media Merge Tool  

A simple yet powerful **Python-based tool** to merge **audio files** 🎵 and **video files** 🎥 with ease.  

This project helps users combine multiple audio tracks or video clips into a single output file using popular Python libraries.  

---

### **🚀 Features**
- Merge multiple **audio files** into one seamless track.  
- Merge multiple **video files** into a single continuous video.  
- Support for common formats: **MP3, WAV, MP4, AVI, MKV**.  
- Lightweight, beginner-friendly, and customizable.  

---

### **🛠️ Technologies Used**
- **Python 3.x** → Core programming language.  
- **MoviePy** → For video editing and merging.  
- **Pydub** → For audio merging and processing.  
- **FFmpeg** (backend) → Required for handling audio/video encoding and decoding.
